企业微信 · 群管理

未登录 内网任意机器可点「获取 Token」直接拉取；若部署在受限网络无法获取，可手动粘贴服务器配置的 WECOM_WEBHOOK_TOKEN 后点「保存」。

拉群（创建群 + 把应用号绑进群）

调用 POST /api/chats → 企微 appchat/create。群主 userid 必须在「应用可见范围」内。

往群里发消息

调用 POST /api/chats/:chatid/messages。应用号必须在该群内（先用「拉群」建群）。

往指定用户发消息（应用号单聊）

调用 POST /api/users/:userid/messages → 企微 message/send，touser 走 userid 列表。目标用户必须在「应用可见范围」内。

查看群信息

调用 GET /api/chats/:chatid → 企微 appchat/get。返回群主、成员列表等。



    
拉人入群

    
调用 PATCH /api/chats/:chatid → 企微 appchat/update，提交 add_user_list。成员 userid 用逗号 / 换行 / 分号分隔，可一次提交多人。

    

      

        
        
      

      

        
        
      

    

    


    
踢人出群

    
调用 PATCH /api/chats/:chatid → 企微 appchat/update，提交 del_user_list。从群中移除成员（群主不可被移除）。

    

      

        
        
      

      

        
        
      

    

    


    
解散群聊

    
调用 POST /api/chats/:chatid/dismiss → 企微 appchat/dismiss。仅限当前应用创建的群，且不可恢复。

    

      
      

        
        
      

    

    


    
撤回群消息

    
调用 POST /api/chats/:chatid/revoke → 企微 appchat/revoke。不填 jobid 时，自动取该群最近一次群发的 jobid（来自发送记录库）。

路由配置（接收渠道 → 发送渠道）

    

      把「接收渠道」收到的消息按模板渲染后，经「发送渠道」推送出去。配置保存在 routes.json；接收到的邮件 / webhook 消息存入 SQLite（recv.db），保留 24 小时后自动清理，不写入任何文本文件。
      
接收渠道仅支持两种：已生成的邮箱账号（在「邮件账号」页生成，经内置 SMTP 收信）/ webhook（外部系统 POST 到 /recv/<routeId>[/code]，地址由本页生成并展示，接收端运行在独立的 8787 端口，与管理界面 3005 隔离；保存后可在列表「接收地址」列复制完整地址）。
      发送渠道：群聊（appchat/send）/ 用户（单聊）。

        本地邮箱源

        webhook 源
        
        
保存后这里会生成完整接收地址：POST /recv/<routeId>[/code]

      


      
      

        syslog 源
        
每条 syslog 路由独立监听一个 UDP/TCP 端口，设备把 syslog 指向该端口即触发路由。端口范围 1-65535，多条路由端口不能重复。

        
        
      


      
      

        
        
      


      
      

        邮件变量：{{from}} {{to}} {{subject}} {{date}} {{body}}（正文纯文本）。
        webhook 变量：POST body 的任意字段（如 {{title}}），原始 JSON 为 {{_raw}}。
        syslog 变量：{{message}} {{host}} {{appname}} {{severity}}(0-7) {{severityName}} {{facility}} {{procid}} {{timestamp}} {{_srcIp}}，原始报文为 {{_raw}}。
      


      

        
        
        
      

    

    

  


  
  

    
邮件账号（本地内置 SMTP 接收）

    

      在此生成仅供本工具接收邮件用的邮箱账号（地址形如 <账号>@<域名>，域名为 wecom-mail.local，SMTP 端口 2525）。
      任何能连到本机该端口的邮件系统，把信发到这些地址，工具就会收下、存盘，并由对应「本地邮箱」路由推送到企业微信。
